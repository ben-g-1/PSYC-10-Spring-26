0. Choosing the right test

More points on this final come from picking the correct test than from any single calculation. The questions usually end with “be as specific as possible,” so a vague answer like “a t-test” or “ANOVA” will lose points. Name the full test, including between- vs within-subjects and one- vs two-way.

Work down from your outcome variable. You’ll probably have to zoom in- I’ve taken a bit to try and reformat it but it’s not worth the headache for something that’s rendering live.

Measurement scales (they show up every term)

The scale of your data decides what is even possible. Two mnemonics from the midterm review:

  • Order, Subtraction, Division, Zero: “Orange Snakes Dunk Zebras.” Ordinal adds order, interval allows subtraction (equal spacing), ratio allows division and has a true zero.
  • Nominal, Ordinal, Interval, Ratio: “No Order Is Right.”

Nominal and ordinal data are usually counts, which points you toward chi-square. Interval and ratio data are scores, which point you toward the mean-based tests and correlation/regression.

Null hypotheses, all in one place
Test Null hypothesis (H₀)
One-sample t / z \(\mu = \mu_0\)
Independent-samples t \(\mu_1 = \mu_2\)
Paired-samples t \(\mu_d = 0\)
One-way ANOVA \(\mu_1 = \mu_2 = \dots = \mu_k\)
Two-way ANOVA No main effect of A; no main effect of B; no A×B interaction
Correlation \(\rho = 0\)
Linear regression slope \(\beta = 0\)
Chi-square the variables are independent / observed frequencies match expected
One-tailed or two-tailed?

The mean-based and relationship tests can be run one- or two-tailed: z-test, one-sample t, two-sample t, Pearson correlation, and linear regression. Chi-square is non-directional by construction, so it is not described as one- or two-tailed- you can think of it as functionally two-tailed if that helps.

1. Central Limit Theorem (CLT)

The Central Limit Theorem states that the sampling distribution of the sample mean approaches a Normal distribution as the sample size (n) grows — regardless of the shape of the underlying population distribution.

Key takeaways

  • The mean of the sampling distribution equals the population mean (μ)
  • The spread (standard error) shrinks as sample size n increases: SE = σ / √n
  • Even highly skewed or bimodal populations produce approximately Normal sampling distributions with enough samples

The tendency for our samples to create this type of normal distribution is what enables most of our other statistical tests.

Why should I care about the Central Limit Theorem?

EVERY parametric test (i.e. everything except chi-square right now) depends on an assumption that there is a “correct” answer to your question, and that if you ask enough people, you will be able to guess or approximate the real answer. That’s why we care about “population” metrics compared to “sample” metrics. We eventually need to assume that our observations are close enough to match the truth because we sampled enough people for each group of our test.

How to use this app: Choose a population shape, set the sample size (n), then drag the “Number of samples” slider slowly from left to right to watch the sampling distribution build up. Try setting your sample size to 1, 10, and 100. Do you see much of a difference beyond that?

Notable milestones for a normally-distributed dataset: 1 sample (almost nothing), 10 samples (rough shape), 100 samples (clearly bell-shaped), 300 samples (well-converged).

However, note how the sample size changes how quickly the correct mean is estimated. If we only take one measurement but include 100 people, we get pretty close to the correct answer.

server <- function(input, output) {

  population <- reactive({

    switch(input$dist,
      normal  = rnorm(50, mean = 21, sd = 1.5),
      skewed  = c(rnorm(40, mean = 19, sd = 1), rnorm(10, mean = 27, sd = 2)),

      bimodal = c(rnorm(100, mean = 18, sd = 1), rnorm(100, mean = 24, sd = 1))

  sample_means <- reactive({
    set.seed(110)
    pop <- population()
    replicate(input$n_sims, mean(sample(pop, input$n, replace = TRUE)))
  })

  output$cltPlot <- renderPlot({
    pop   <- population()
    means <- sample_means()
    n_sims <- input$n_sims
    true_mean <- mean(pop)

    par(mfrow = c(1, 2), mar = c(4, 4, 3, 1))

    # Panel 1: Population
    hist(pop,
         breaks = 20,
         col    = "skyblue",
         border = "white",
         main   = "Population Distribution",
         xlab   = "Value",
         xlim   = range(pop) + c(-1, 1))
    abline(v = true_mean, col = "red", lwd = 3)
    legend("topleft", legend = paste("μ =", round(true_mean, 2)),
           col = "red", lwd = 2, bty = "n", cex = 0.85)

    # Panel 2: Sampling distribution
    xlim_range <- range(c(means, pop)) + c(-1, 1)
    hist(means,
         breaks = max(5, min(30, n_sims %/% 5)),
         col    = "tomato",
         border = "white",
         main   = sprintf("Sampling Distribution\n(%d sample%s, n = %d)",
                          n_sims, if (n_sims == 1) "" else "s", input$n),
         xlab   = "Sample mean",
         xlim   = xlim_range)
    abline(v = true_mean,   col = "red",  lwd = 3)
    abline(v = mean(means), col = "blue", lwd = 3, lty = 2)
    legend("topleft",
           legend = c(paste("True μ =", round(true_mean, 2)),
                      paste("x̄ of means =", round(mean(means), 2))),
           col = c("red", "blue"), lwd = 2, lty = c(1, 2), bty = "n", cex = 0.85)
  })

  output$callout <- renderUI({
    means     <- sample_means()
    true_mean <- mean(population())
    n_sims    <- input$n_sims
    se_theory <- sd(population()) / sqrt(input$n)
    se_obs    <- sd(means)
    milestone <- if (n_sims == 1) {
      "Just 1 sample — almost no distribution to see yet."
    } else if (n_sims <= 10) {
      paste0("After ", n_sims, " samples: shape is very rough.")
    } else if (n_sims <= 100) {
      paste0("After ", n_sims, " samples: bell shape is emerging.")
    } else {
      paste0("After ", n_sims, " samples: well-converged to Normal.")
    }
    tags$div(
      style = "background:#f0f4f8; border-left:4px solid #2c7bb6; padding:10px 14px; margin-top:10px; border-radius:4px;",
      tags$b("Snapshot: "), milestone, tags$br(),
      sprintf("Running mean of sample means: %.3f (true μ = %.3f)", mean(means), true_mean), tags$br(),
      sprintf("Observed SE: %.3f | Theoretical SE (σ/√n): %.3f", se_obs, se_theory)
    )
  })
}

2. Z-Test

A z-test is used when we know the population standard deviation (σ) — a rare but instructive scenario (e.g., when a large historical dataset gives us σ exactly).

\[z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}}\]

Because σ is known, we compare to the Standard Normal (not a t-distribution). The critical value is basically always ±1.96 for α = 0.05, two-tailed, regardless of n. This is directly in contrast to t-tests, where the critical values shrink as n incraeses.

The Null Hypothesis

The population mean equals our hypothesized value:

\[H_0: \mu = \mu_0\]

where \(\mu_0\) is the specific value we’re testing against (e.g., a national average).

How to use this app: Notice how the z-test and t-test give nearly identical results when n is large — the t-distribution approaches Normal.

server <- function(input, output) {

  z_stat <- reactive({
    (input$sample_mean - input$mu0) / (input$sigma / sqrt(input$n))
  })

  p_val <- reactive({
    2 * pnorm(-abs(z_stat()))
  })

  output$zPlot <- renderPlot({
    z    <- z_stat()
    z_c  <- 1.96
    x    <- seq(-5, 5, length.out = 500)
    y    <- dnorm(x)

    par(mar = c(4, 4, 3, 1))
    plot(x, y, type = "l", lwd = 2,
         main = "Standard Normal Distribution",
         xlab = "z", ylab = "Density")
    x_lo <- x[x <= -z_c]; x_hi <- x[x >= z_c]
    polygon(c(min(x_lo), x_lo, -z_c), c(0, dnorm(x_lo), 0),
            col = rgb(0.5, 0.5, 0.5, 0.3), border = NA)
    polygon(c(min(x_hi), x_hi, z_c), c(0, dnorm(x_hi), 0),
            col = rgb(0.5, 0.5, 0.5, 0.3), border = NA)
    abline(v =  z,   col = "navy",   lwd = 2.5, lty = 2)
    abline(v =  z_c, col = "tomato", lwd = 1.5, lty = 3)
    abline(v = -z_c, col = "tomato", lwd = 1.5, lty = 3)
    legend("topleft",
           legend = c(sprintf("z = %.3f", z),
                      "±z_crit = ±1.96",
                      "Rejection region (α=0.05)"),
           col = c("navy", "tomato", rgb(0.5, 0.5, 0.5, 0.5)),
           lwd = c(2.5, 1.5, 8), lty = c(2, 3, 1), bty = "n", cex = 0.85)
  })

  output$zResults <- renderUI({
    z      <- z_stat()
    p      <- p_val()
    reject <- p < 0.05
    color  <- if (reject) "#c0392b" else "#27ae60"
    decision <- if (reject)
      sprintf("Reject H₀: μ₀ = %.1f (p < 0.05)", input$mu0)
    else
      sprintf("Fail to reject H₀: μ₀ = %.1f (p ≥ 0.05)", input$mu0)
    tags$div(
      style = paste0("background:#f9f9f9; border-left:4px solid ", color,
                     "; padding:10px 14px; margin-top:10px; border-radius:4px;"),
      tags$b("Results:"), tags$br(),
      sprintf("z = %.3f", z), tags$br(),
      sprintf("p-value = %.4f", p), tags$br(),
      tags$b(decision)
    )
  })
}

3. One-Sample t-Test

A one-sample t-test asks: Is our sample mean significantly different from a hypothesized population mean (μ₀)? We often test against the hypothesis that our population mean is 0, and we test our sample after subtracting the sample mean from all observations.

We use a t-statistic (not z) because σ is unknown and must be estimated from the sample:

\[t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}, \quad df = n - 1\]

The p-value is the probability of observing a t-statistic this extreme (or more) if H₀ were true.

The Null Hypothesis

The population mean equals our hypothesized value:

\[H_0: \mu = \mu_0\]

The only difference from the z-test is that we estimate \(\sigma\) from our sample (as \(s\)) rather than knowing it.

How to use this app: Adjust the sliders to see how moving μ₀ further from the observed mean, increasing n, or decreasing s all affect the t-statistic and p-value.

server <- function(input, output) {

  stats <- reactive({
    t_stat <- (input$sample_mean - input$mu0) / (input$sample_sd / sqrt(input$n))
    df     <- input$n - 1

    s    <- stats()
    df   <- s$df

    par(mar = c(4, 4, 3, 1))
    plot(x, y, type = "l", lwd = 2,
         main = sprintf("t-Distribution (df = %d)", df),
         xlab = "t", ylab = "Density")

    x_lo <- x[x <= -t_crit]; x_hi <- x[x >= t_crit]
    polygon(c(min(x_lo), x_lo, -t_crit), c(0, dt(x_lo, df), 0),
            col = rgb(0.5, 0.5, 0.5, 0.3), border = NA)
    polygon(c(min(x_hi), x_hi, t_crit), c(0, dt(x_hi, df), 0),
            col = rgb(0.5, 0.5, 0.5, 0.3), border = NA)

    abline(v = t_ob,    col = "navy",   lwd = 2.5, lty = 2)
    abline(v =  t_crit, col = "tomato", lwd = 1.5, lty = 3)
    abline(v = -t_crit, col = "tomato", lwd = 1.5, lty = 3)
    legend("topleft",
           legend = c(sprintf("t = %.3f", t_ob),
                      sprintf("±t_crit = ±%.3f", t_crit),
                      "Rejection region (α=0.05)"),
           col = c("navy", "tomato", rgb(0.5, 0.5, 0.5, 0.5)),
           lwd = c(2.5, 1.5, 8), lty = c(2, 3, 1), bty = "n", cex = 0.85)
  })

  output$results <- renderUI({
    s      <- stats()
    reject <- s$p < 0.05
    color  <- if (reject) "#c0392b" else "#27ae60"
    decision <- if (reject)
      sprintf("Reject H₀: μ₀ = %.1f (p < 0.05)", input$mu0)
    else
      sprintf("Fail to reject H₀: μ₀ = %.1f (p ≥ 0.05)", input$mu0)

      style = paste0("background:#f9f9f9; border-left:4px solid ", color,

      sprintf("t(%d) = %.3f", s$df, s$t), tags$br(),
      sprintf("p-value = %.4f", s$p), tags$br(),
      tags$b(decision)
    )
  })
}

4. Two-Sample t-Test

A two-sample t-test tests whether the means of two groups differ:

\[H_0: \mu_1 = \mu_2\]

We can use either independent or dependent tests based on what our two groups represent.

When to use which:

  • Independent samples t-test: Different subjects in each group (e.g., treatment vs. control with separate participants)
  • Paired t-test: Same subjects measured twice (e.g., pre-test vs. post-test, or same subject across two conditions)

4a. Independent samples

The Null Hypothesis

The two population means are equal:

\[H_0: \mu_1 = \mu_2\]

In other words, the difference between the means is zero: \(\mu_1 - \mu_2 = 0\).

Two variants:

  • Pooled (equal variances assumed): combines variance estimates; uses n₁ + n₂ − 2 df
  • Welch (unequal variances): uses separate variance estimates with adjusted (Satterthwaite) df — generally safer, but not something you need to know for this course!. It might be instructive for you to see the difference between the two though, especially when setting the variances far apart from one another. The degrees of freedom for this version are adjusted.

CRITICAL: DON’T WORRY ABOUT THE WELCH TEST FOR ANYTHING OTHER THAN CURIOSITY (for now at least)

How to use this app: Slide Group 1 and Group 2 means apart to see when the test becomes significant. Toggle between pooled and Welch to compare.

    x_lo <- x[x <= -t_crit]; x_hi <- x[x >= t_crit]
    if (length(x_lo) > 1)
      polygon(c(min(x_lo), x_lo, -t_crit), c(0, dt(x_lo, df), 0),

      sprintf("p-value = %.4f", p_val), tags$br(),
      tags$b(decision)
    )
  })
}

4b. Paired Samples (Dependent t-Test)

A paired t-test is used when the same subjects are measured under two conditions (e.g., before/after treatment, left hand vs right hand, condition A vs condition B for the same person).

The Null Hypothesis

There is no change in the mean when comparing the two observations:

\[H_0: \mu_d = 0\]

where \(\mu_d\) is the mean of the difference scores (Condition 2 − Condition 1).

Instead of comparing two independent groups, we compute the difference score for each subject and test whether the mean difference is significantly different from zero:

\[t = \frac{\bar{d} - \mu_0}{s_d / \sqrt{n}}, \quad df = n - 1\]

where \(\bar{d}\) is the mean of the difference scores, \(s_d\) is the SD of the differences, and \(n\) is the number of pairs (not total observations).

The Key Insight

By using the same subjects in both conditions, we can subtract out individual differences. This is analogous to the relationship between the between-groups ANOVA and within-groups (repeated measures) ANOVA in Section 6 — using the same subjects across conditions removes between-subject variability from the error term, dramatically increasing statistical power.

How to use this app: Adjust the between-subject SD and within-subject (error) SD to see how the paired test gains power. When between-subject variability is high but within-subject error is low, the paired test dramatically outperforms the independent test on the same data. 5. Confidence Intervals & Effect Sizes

Hypothesis testing gives you a yes/no decision. Estimation asks a different question: what range of values is plausible for the parameter? A confidence interval sets an upper and lower limit that, across repeated samples, contains the population value a set percentage of the time.

\[\text{CI} = \bar{x} \pm t(s_{\bar{x}}), \quad s_{\bar{x}} = \frac{s}{\sqrt{n}}\]

The link between a CI and a hypothesis test

A 95% confidence interval and a two-tailed test at α = 0.05 carry the same information. If the hypothesized value \(\mu_0\) falls outside the interval, you would reject H₀. If it falls inside, you retain H₀. Watch the decision box flip as you slide \(\mu_0\) across an interval edge.

Effect sizes answer “how big,” which significance alone never tells you. The formula sheet gives you three:

  • Cohen’s d \(= \dfrac{\bar{x} - \mu_0}{s}\), in standard-deviation units (small 0.2, medium 0.5, large 0.8).
  • Proportion of variance \(r^2 = \dfrac{t^2}{t^2 + df}\) (item 11), the share of variability explained.
  • Omega-squared \(\omega^2 = \dfrac{t^2 - 1}{t^2 + df}\) (item 12), a more conservative version of the same idea.

How to use this app: Move \(\mu_0\) toward and past the interval edge and watch the decision flip. Then change \(n\) and \(s\) to see the interval tighten or widen, and notice that Cohen’s d does not depend on \(n\) while the p-value does.

6. One-Way ANOVA

ANOVA (Analysis of Variance) tests whether the variance of 2 or more group means are equal. In practice, it’s usually used for 3 or more groups, but it’s important to understand that you can use it for comparing two groups.

Why do we call it an analysis of VARIANCE if we care about the means?

Because the way you detect differences in means is by analyzing variance — specifically, by comparing two kinds of it.

When group means differ, the data are spread out between groups more than you would expect by chance. ANOVA quantifies this by asking how much of the total variance is explained by group membership (between-groups variance) versus how much is just noise within each group (within-groups variance). The F-ratio is literally that comparison:

\[F = \frac{\text{variance between groups}}{\text{variance within groups}}\]

If the group means are all equal, those two quantities should be about the same, so F ≈ 1. If the means differ, the between-groups variance inflates and F grows.

So “analysis of variance” is accurate: the test never checks \(\mu_1 = \mu_2 = \mu_3\) directly. It infers a difference by decomposing and comparing variances. The means are what you care about; variance is the tool that gets you there.

Performing an ANOVA on only 2 groups

One-way ANOVA on two groups actually gives you the same p-value as a pooled two-sample t-test!

In other words, when performing an ANOVA for two groups:

\[F = t^2\]

Remember that this is NOT the case when there are 3 or more groups, which is the usual time you’ll see ANOVA being used.

The Null Hypothesis

There is no difference between any of the group means:

\[H_0: \mu_1 = \mu_2 = \mu_3 = \dots = \mu_k\]

If you get a significant p-value, the ANOVA only tells you that something differs. Finding which groups differ takes a post-hoc test, and the logic behind those matters enough to get its own section: see Section 7 right below.

It partitions total variance into:

  • Between-groups (SS_B): variance due to group differences
  • Within-groups / Error (SS_W): variance within groups

The F-statistic = MS_Between / MS_Within. Large F indicates that the means differ more than chance. Importantly, the test never compares the means directly: it infers that they differ by comparing variances.

\[F = \frac{MS_{Between}}{MS_{Within}} = \frac{SS_B / (k-1)}{SS_W / (N-k)}\]

6b. Within-Groups (Repeated Measures) ANOVA

The Null Hypothesis

There is no change in the group mean across all observations:

\[H_0: \mu_1 = \mu_2 = \dots = \mu_k\]

where each \(\mu_i\) represents the mean for the same subjects measured under condition \(i\).

The same subjects are measured across all conditions. Subject-to-subject variability is removed from the error term, dramatically increasing statistical power. We do this by first calculating the mean difference WITHIN SUBJECT for each of the observations. This is how we had a data table that started out as 1000+ rows eventually turn into just 20 rows that we could perform our stats on in HW3; for each of the 4 conditions, we took the subject’s average response, then compared those 4 averages per person. The “Watch the error disappear” demo back in Section 4b shows this same trick with two conditions; the repeated-measures ANOVA simply extends it to more.

\[F_{RM} = \frac{MS_{Conditions}}{MS_{Conditions \times Subjects}}\]

The line plot below shows individual “subjects” across conditions. Parallel lines are good and indicate low within-subject error. This results in a high F.

REMEMBER: While t-scores are universally accepted as having clearly delineated conventional effect thresholds (d = 0.2 | 0.5 | 0.8), F tests do not have common effect sizes. Depending on your dataset, explaining 25% of the variance could be excellent! However, if you’re looking at a cancer screening test, it is likely far too low.

7. Post-Hoc Tests & Multiple Comparisons

A significant ANOVA tells you that the group means are not all equal. It does not tell you which groups differ. For that we follow up with a post-hoc test. In this class we used Tukey’s Honestly Significant Difference (HSD), which looks a lot like running a t-test on every pair of groups.

The obvious question is why we need a special test instead of just running those t-tests ourselves. The answer comes down to making sure that you HONESTLY have a difference, and we do that by keeping track of how many total comparisons are being made. Every test you run carries its own chance of a false positive. If you do enough tests, eventually something is going to slip under that 5% line by accident. One test at p = 0.045 is fine. Ten tests, and your effective threshold should be MUCH lower, because each comparison brings its own chance of a fluke. With m comparisons, the chance of at least one false positive is approximately:

\[P(\text{at least one false positive}) \approx 1 - (1 - \alpha)^m\]

Four groups already mean 6 pairwise comparisons, which pushes the family-wise error rate past 26%. Tukey’s HSD accounts for the number of comparisons and holds the overall false-positive rate near 5%.

How to use this app: Every group here is drawn from the SAME population, so any “significant” pairwise difference is a false positive by construction. Add groups and watch how often plain t-tests find something that is not there, while Tukey stays honest.

8. Two-Way ANOVA

A two-way between-subjects ANOVA has two factors (call them A and B), with different subjects in every cell. Instead of one question it asks three, so it runs three hypothesis tests:

  • Main effect of A: averaging over B, do the levels of A differ?
  • Main effect of B: averaging over A, do the levels of B differ?
  • Interaction (A × B): does the effect of A depend on the level of B?
Reading the interaction plot

Plot the cell means with one line per level of B.

  • Parallel lines mean no interaction. The gap between lines is the same at every level of A.
  • Lines that converge, cross, or fan out signal an interaction. The effect of one factor changes depending on the other.

When the interaction is significant, interpret it first, using simple main effects, before reading the main effects on their own.

Naming the parts (a common fill-in question)

For a design like “type of media exposure (violent, non-violent, none) and age group (early vs late adolescent) on aggression scores”:

  • Dependent variable: aggression scores (the measured outcome).
  • Factor A: media exposure, with 3 levels.
  • Factor B: age group, with 2 levels.

This is a 3 × 2 design. The app below uses a 2 × 2 so the interaction plot stays readable.

How to use this app: Set the four cell means to make the two lines parallel and watch the interaction F drop toward nonsignificance. Then drag one corner to cross the lines and watch the interaction F climb.

9. Correlation (Pearson’s r)

Correlation describes the strength and direction of the linear relationship between two continuous variables. Pearson’s r runs from −1 to +1: the sign is the direction, and the distance from 0 is the strength. A perfect correlation of 1 means every point sits exactly on a straight line: each 1 SD increase in X comes with exactly 1 SD increase in Y. Careful, though: r says nothing about the raw-unit slope. A perfect r can belong to a steep line or a shallow one; the slope is the regression line’s job (Section 10).

\[r = \frac{SS_{XY}}{\sqrt{SS_X \, SS_Y}}, \qquad r^2 = \text{proportion of variance shared}\]

On the exam you may be handed the sums of squares and asked for r and the effect size. With \(SS_{XY}\) and the product \(SS_X \cdot SS_Y\) in hand, r is one division and a square root, and \(r^2\) is just r squared (item 25, then the coefficient of determination).

Significance depends on n, not just the size of r

A given r is significant only if it beats the critical value for your degrees of freedom (\(df = n - 2\)). With small samples even a fairly large r can fail to reach significance. For example, \(r = .26\) with \(n = 40\) does not clear the two-tailed .05 cutoff. Watch the critical value in the results box as you change n.

What correlation cannot do
  • Causation. A relationship does not tell you which variable drives which, or whether a third variable drives both.
  • Outliers. A single off-trend point can inflate or hide a correlation. Use the toggle below to see it.
  • Non-linearity. r only measures the straight-line part of a relationship. A strong curved pattern can still give r near 0.
  • Restricted range narrows the spread of scores and shrinks r.

How to use this app: Set the underlying relationship strength and sample size, then read the observed r, its r², and whether it clears the critical value. Flip on the outlier to see how much one point can move the result.

10. Linear Regression

Correlation describes a relationship; linear regression fits an equation to it so you can predict one variable from another.

\[\hat{Y} = bX + a\]

The predictor X is the known variable; the criterion Y is the one you predict. The slope b is the change in Y for a one-unit change in X (item 27). The intercept a is the predicted Y when X = 0. The line is chosen by least squares, the line that makes the squared vertical distances from the points (the residuals) as small as possible.

Residuals and homoscedasticity

A residual is the gap between an observed point and the line: observed minus predicted. Plotting residuals against X is how you check the regression’s assumptions.

  • Homoscedastic: residuals show roughly even spread across X. This is what you want.
  • Heteroscedastic: the spread fans out or narrows across X. The line still fits, but the model’s error is not constant, which violates an assumption.

Use the toggle to switch between the two and watch the residual plot.

Prediction is just plugging in

To predict, substitute an X into the fitted equation. For \(\hat{Y} = -0.13X + 1.72\), a patient who attends 6 sessions has a predicted score of \(-0.13(6) + 1.72 = 0.94\). You will not fit a regression by hand on this exam, but you are expected to read off the slope and intercept and predict from them.

How to use this app: Set a slope and intercept, then move the prediction slider to read a predicted Y off the line. Turn on heteroscedasticity and watch the residual plot fan out while the line itself barely moves.

    ypred <- co[1] + co[2] * input$xpred
    spread_note <- if (input$hetero)
      "Residuals fan out across X: heteroscedastic (assumption violated)."
    else
      "Residuals are evenly spread across X: homoscedastic (assumption met)."
    tags$div(
      style = "background:#f9f9f9; border-left:4px solid #2c7bb6; padding:10px 14px; margin-top:10px; border-radius:4px;",
      tags$b(sprintf("Fitted equation: Ŷ = %.3f·X + %.3f", co[2], co[1])), tags$br(),
      sprintf("r² = %.3f  (about %.0f%% of the variance in Y is explained by X)", r2, 100 * r2), tags$br(),
      sprintf("Predicted Y at X = %.1f:  Ŷ = %.2f", input$xpred, ypred), tags$br(),
      tags$em(spread_note)
    )
  })
}

11. Chi-Square

Chi-square is for counts in categories, not means. It compares the frequencies you observed against the frequencies you would expect. There are two versions, and the exam wants you to name which one.

\[f_e = \frac{\text{row total} \times \text{column total}}{N}, \qquad \chi^2 = \sum \frac{(f_o - f_e)^2}{f_e}\]

  • Goodness of fit: one categorical variable against a hypothesized distribution. \(df = k - 1\), where k is the number of categories.
  • Test of independence: two categorical variables, testing whether they are associated. \(df = (\text{rows} - 1)(\text{columns} - 1)\).
The two chi-squares, side by side

Both flavors use the exact same statistic. What changes is the question, and where the expected frequencies come from.

Goodness of fit Test of independence
Variables one categorical variable two categorical variables
Question does the observed distribution match a claimed one? are the two variables associated?
H₀ observed frequencies match the expected distribution the variables are independent
Expected frequencies from the hypothesized proportions (equal or not) row total × column total / N
df k − 1 (rows − 1)(columns − 1)
Feels like a one-sample test for categories a correlation for categories

Two wording cues on the exam: “matches / differs from an expected or claimed distribution” points to goodness of fit, while “related to / associated with / depends on” points to independence. One more quirk worth remembering: goodness of fit is the rare test where retaining the null can be the interesting result, like confirming a die is fair.

Assumptions, including the soft one
  • Each observation falls in one and only one category.
  • Observations are independent (different, unrelated participants). Splitting one person’s count across two categories breaks this.
  • The soft assumption that researchers sometimes bend: every expected frequency should be at least 5. The app warns you when this is violated.
Effect size

For a 2 × 2 table, the phi coefficient \(\varphi = \sqrt{\chi^2 / N}\) (item 30). For larger tables, Cramér’s V \(= \sqrt{\chi^2 / (N \cdot df_{smaller})}\) (item 31), where \(df_{smaller}\) is the smaller of (rows − 1) and (columns − 1). For a 2 × 2 the two are identical.

How to use this app: Switch between the two tests. In goodness-of-fit, push one category’s count far from the others and watch χ² grow. In the independence test, make the rows proportional to each other (no association) and watch χ² fall toward 0.

server <- function(input, output) {

  analysis <- reactive({
    if (input$mode == "gof") {
      obs <- c(input$o1, input$o2, input$o3, input$o4)
      test <- chisq.test(obs)
      list(mode = "gof", obs = obs, exp = test$expected,
           stat = unname(test$statistic), df = unname(test$parameter),
           p = test$p.value, N = sum(obs))
    } else {
      m <- matrix(c(input$c11, input$c12, input$c21, input$c22),
                  nrow = 2, byrow = TRUE)
      test <- chisq.test(m, correct = FALSE)
      list(mode = "ind", obs = m, exp = test$expected,
           stat = unname(test$statistic), df = unname(test$parameter),
           p = test$p.value, N = sum(m))
    }
  })

  output$chiPlot <- renderPlot({
    a <- analysis()
    par(mar = c(4, 4, 3, 1))
    if (a$mode == "gof") {
      mat <- rbind(Observed = a$obs, Expected = a$exp)
      barplot(mat, beside = TRUE, col = c("navy", "gray70"), border = "white",
              names.arg = paste0("C", 1:4),
              main = "Observed vs Expected", ylab = "Frequency")
      legend("topright", legend = c("Observed", "Expected"),
             fill = c("navy", "gray70"), bty = "n")
    } else {
      barplot(a$obs, beside = TRUE, col = c("navy", "tomato"), border = "white",
              names.arg = c("Col 1", "Col 2"),
              main = "Observed counts by row", ylab = "Frequency")
      legend("topright", legend = c("Row 1", "Row 2"),
             fill = c("navy", "tomato"), bty = "n")
    }
  })

  output$expTable <- renderTable({
    a <- analysis()
    if (a$mode == "gof") {
      data.frame(Category = paste0("C", 1:4),
                 Observed = a$obs, Expected = round(a$exp, 2),
                 check.names = FALSE)
    } else {
      e <- round(a$exp, 2)
      data.frame(Row = c("Row 1", "Row 2"),
                 "Col 1 (exp)" = e[, 1], "Col 2 (exp)" = e[, 2],
                 check.names = FALSE)
    }
  }, striped = TRUE, bordered = TRUE)

  output$chiResults <- renderUI({
    a <- analysis()
    reject <- a$p < 0.05
    color  <- if (reject) "#c0392b" else "#27ae60"
    rows <- nrow(as.matrix(a$exp)); cols <- ncol(as.matrix(a$exp))
    df_small <- if (a$mode == "ind") min(rows - 1, cols - 1) else 1
    eff <- sqrt(a$stat / (a$N * df_small))
    eff_name <- if (a$mode == "ind" && rows == 2 && cols == 2) "φ (phi)" else
                if (a$mode == "ind") "Cramér's V" else NA
    decision <- if (reject) "Reject H₀: the frequencies differ from expected / the variables are associated."
                else "Retain H₀: no significant departure from expected."
    warn <- if (min(a$exp) < 5)
      tags$div(style = "color:#c0392b;", "Warning: an expected frequency is below 5 (assumption violated).")
    else NULL
    tags$div(
      style = paste0("background:#f9f9f9; border-left:4px solid ", color,
                     "; padding:10px 14px; margin-top:10px; border-radius:4px;"),
      tags$b(sprintf("χ²(%d) = %.3f, p = %.4f", a$df, a$stat, a$p)), tags$br(),
      if (a$mode == "ind") tags$span(sprintf("Effect size %s = %.3f", eff_name, eff)) else
        tags$span(sprintf("Total N = %d, k = 4 categories", a$N)),
      tags$br(),
      tags$b(decision),
      warn
    )
  })
}

shinyApp(ui = ui, server = server)
